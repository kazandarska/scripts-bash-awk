# bash-awk-NF
awk calculate row arithmetic mean else if

A simple but efficient Bash+AWK script designed for line-by-line processing numerical datasets.

What I have learned from this project:
- Data Stream Management: for loop inside AWK
- Built-n Variables: understanding the difference between NR and NF
- System Integration: safely passing data and conditional logic form Bash to AWK without mixing their respective syntaxes
- Output Formating: using print to round floating-point numbers (%.2f)
